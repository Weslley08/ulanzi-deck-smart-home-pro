Conectar Home Assistant

Estas instruções explicam como autorizar a integração e selecionar seus dispositivos no Ulanzi Studio.

Passo a passo

  1. 1Abra a interface web do seu Home Assistant e faça login com uma conta que tenha acesso aos dispositivos.
  2. 2Abra seu perfil de usuário e entre na seção Segurança (Security).
  3. 3Em Long-lived access tokens, selecione Criar token e atribua um nome como Ulanzi Smart Home PRO.
  4. 4Copie o token no momento da criação e mantenha-o em segredo; não compartilhe nem inclua em perfis exportados.
  5. 5Identifique a URL base do Home Assistant. A versão atual do plugin exige HTTPS para hosts remotos ou HTTP somente em localhost/127.0.0.1.
  6. 6No Ulanzi Studio, abra a ação Home Assistant, preencha URL e token (se não tiverem sido detectados), clique Test and connect; depois selecione o dispositivo e a ação.

Problemas comuns e segurança

Se o Home Assistant funcionar apenas em http://192.168.x.x:8123, a versão atual não aceita essa conexão em texto claro. Configure HTTPS confiável ou use acesso local seguro.

Se a lista estiver vazia, confira permissões da conta, URL, validade do token e acesso à rede.

Nunca compartilhe tokens, Client Secrets ou credenciais por mensagens. A versão atual mantém credenciais digitadas apenas durante a sessão; elas não são armazenadas nos perfis do Studio.

Os serviços e nomes dos menus podem mudar. Consulte os links oficiais para instruções atualizadas.
