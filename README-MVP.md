# Smart Home PRO — MVP implementation

Status: **development** (not a verified installable release).

This branch implements the first Home Assistant adapter with REST discovery, safe command allowlisting, WebSocket state updates, property inspector entity selection, and basic action icons.

See [development instructions](docs/DEVELOPMENT.md), [provider status](docs/INTEGRATIONS.md), and [security notes](SECURITY.md).

Other ecosystems are not yet implemented. Installation and real D200 behavior have not yet been confirmed. No release should be published from this initial commit.
